# 🔐 API Security

## ❌ Wrong Method

```python
"api_key": "YOUR_API_KEY"
```

---

## ✅ Secure Method

### Create:
```bash
.streamlit/secrets.toml
```

### Add:
```toml
SERPAPI_KEY="YOUR_API_KEY"
```

### Use in Python:
```python
"api_key": st.secrets["SERPAPI_KEY"]
```
